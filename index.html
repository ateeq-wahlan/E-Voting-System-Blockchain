7-Stage Decentralized E-Voting Architecture

SYSTEM WORKFLOW
  1. Stage 1 — Citizen Electoral Enrollment (`Form-6` / `register` Table): Eligible voters enroll with their EPIC ID, constituency address, and biometric portrait to generate a 256-bit facial signature.
  2. Stage 2 — Zero-Knowledge Nullifier Derivation (`BallotCipher`): A one-way `PBKDF2-HMAC-SHA256` nullifier (`zk_nullifier_...`) decouples voter identity from on-chain ballot records while enforcing strict one-person-one-vote eligibility.
  3. Stage 3 — Electoral Commission Mandate Management (`Form-2A` & `Form-2B`): Authenticated EC Administrators gazette party candidates (`addparty`) or execute official Form-2B mandate revocations.
  4. Stage 4 — Unified Biometric Verification & Camera Registration Popup: Selecting a Voter ID opens the Biometric Popup—displaying their registered portrait (or activating the camera to capture & register one if missing) and pre-filling their voter details for voting.
  5. Stage 5 — Additive Homomorphic Ballot Encryption: The selected candidate choice is sealed in an AES-PBKDF2 stream cipher and paired with a homomorphic commitment (`0x...`).
  6. Stage 6 — SHA-256 Proof-of-Work Mining (`Blockchain.py`): The mining node increments `block.nonce` until `compute_hash()` produces a SHA-256 digest starting with `'00'` (`difficulty = 2`).
  7. Stage 7 — 5-Second Ballot Confirmation Popup & Public Consensus Audit: Casting a vote triggers an instant 5-second auto-closing confirmation popup showing the voter's details, party symbol, and mined block hash.

Core Cryptographic Engine (`Block.py` & `Blockchain.py`)

SHA-256 PROOF-OF-WORK 
class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.nonce = 0

    def compute_hash(self):
        block_string = json.dumps(self.__dict__, sort_keys=True)
        return sha256(block_string.encode()).hexdigest()

class Blockchain:
    difficulty = 2  # Proof-of-Work leading '00' target

    def proof_of_work(self, block):
        block.nonce = 0
        computed_hash = block.compute_hash()
        while not computed_hash.startswith('0' * Blockchain.difficulty):
            block.nonce += 1
            computed_hash = block.compute_hash()
        return computed_hash
