SYSTEM ARCHITECTURE (FIG. 1)
  1. Step 1 — Voter Registration (`register` / `Voter` Table): Citizens enroll with username, contact, constituency address, and a facial biometric frame (`320×240` webcam capture).
  2. Step 2 — Cryptographic Identity Hashing: A 256-bit biometric descriptor and HMAC-SHA256 Zero-Knowledge Nullifier (`zk_nullifier_...`) are derived so voter privacy is preserved on the public ledger.
  3. Step 3 — Electoral Roll Distribution: Verified voter rolls and Admin-registered party ballots (`addparty`) are synchronized across polling stations.
  4. Step 4 — Biometric Webcam Authentication: Before unlocking the ballot, the voter captures a live webcam snapshot (`Take Snapshot` → `Validate User`) to prevent impersonation.
  5. Step 5 — Homomorphic Ballot Encryption: Selected candidate choice is encrypted via PBKDF2-AES stream cipher and paired with an additive homomorphic commitment (`0x...`).
  6. Step 6 — Proof-of-Work MiningNode (`Blockchain.py`): The mining node increments `block.nonce` until `compute_hash()` produces a SHA-256 digest starting with `'00'` (`difficulty = 2`).
  7. Step 7 — Real-Time Public Audit & Tally: Every stakeholder can verify `Previous Hash → Current Hash` linkage and audit real-time election tallies without trusting a central authority.

class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.nonce = 0

    def compute_hash(self):
        block_string = json.dumps(self.__dict__, sort_keys=True)
        return sha256(block_string.encode()).hexdigest()

class Blockchain:
    difficulty = 2  # Proof-of-Work leading '00' target

    def proof_of_work(self, block):
        block.nonce = 0
        computed_hash = block.compute_hash()
        while not computed_hash.startswith('0' * Blockchain.difficulty):
            block.nonce += 1
            computed_hash = block.compute_hash()
        return computed_hash
